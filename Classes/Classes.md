# Диаграмма классов приложения для прослушивания аудиокниг

![Диаграмма классов](https://github.com/NoDanate/Individual-Project-BV312/blob/bdc5f9e7fe228dc6d6d25fbd8f16fc1d8632d01b/Classes/Classes.png)

## Сущности

### 1. Account (Аккаунт)
**Описание:** Учётная запись пользователя в системе. Может принадлежать обычному пользователю или администратору.

**Атрибуты:**
- **id** — Уникальный идентификатор записи в БД
- **login** — Уникальное имя пользователя для входа в систему
- **pass** — Пароль для авторизации (в перспективе — хранение в виде md5)
- **roleid** — Идентификатор роли: 1 — администратор, 2 — обычный пользователь

**Методы:**
- `__construct(login, pass, id)` — Конструктор объекта
- `intoDb()` — Добавление нового аккаунта в базу данных
- `fromDb(id)` — Получение аккаунта из БД по его ID
- `fromDbName(Name)` — Получение аккаунта из БД по логину

---

### 2. Book (Аудиокнига)
**Описание:** Сущность, содержащая полную информацию об аудиокниге и методы для работы с каталогом.

**Атрибуты:**
- **id** — Уникальный идентификатор
- **name** — Название книги
- **author** — Автор произведения
- **genre** — Жанр (например, роман, фэнтези, детектив)
- **description** — Краткое описание сюжета
- **imagepath** — Путь к файлу обложки книги
- **speaker** — Имя диктора (рассказчика)
- **bookpath** — Путь к файлу с аудиокнигой

**Методы:**
- `__construct(id, name, author, genre, description, imagepath, speaker, bookpath)` — Конструктор
- `intoDb()` — Добавление книги в БД
- `fromDb(id)` — Получение книги по ID
- `GetItems(genre)` — Получение списка книг (с фильтрацией по жанру)
- `GetUniqueItems(genre)` — Получение уникальных книг (без дублей по названию и автору, если книга читается разными дикторами)
- `getBookRating(id)` — Получение средней оценки и количества голосов
- `getBookSpeakers(name, author)` — Получение списка всех дикторов для конкретной книги
- `searchUniqueBooks(query)` — Поиск уникальных книг по названию или автору
- `Draw()` — Отрисовка карточки книги для каталога
- `DrawCart()` — Отрисовка карточки книги для страницы избранного

---

### 3. BookUser (Связь пользователя с книгой)
**Описание:** Промежуточная сущность для реализации связей "избранное" и "оценки пользователя".

**Атрибуты:**
- **user_id** — Внешний ключ на таблицу Account
- **book_id** — Внешний ключ на таблицу Book
- **rate** — Оценка, выставленная пользователем книге (целое число, может быть NULL)

**Методы:**
- `__construct(user_id, book_id, rate)` — Конструктор
- `intoDb()` — Добавление книги в избранное пользователя
- `deleteFromDb(user_id, book_id)` — Удаление книги из избранного
- `getUserBooks(user_id)` — Получение всех книг в избранном у пользователя
- `isBookInWishlist(user_id, book_id)` — Проверка, находится ли книга в избранном
- `getUserIdByLogin(login)` — Получение ID пользователя по его логину
- `updateRating(user_id, book_id, rate)` — Добавление или обновление оценки пользователя на книгу
- `getUserRating(user_id, book_id)` — Получение оценки, которую поставил пользователь

## Вспомогательные утилиты

### 4. Tools (Инструменты)
**Описание:** Статический класс с вспомогательными методами для работы с системой.

**Методы:**
- `connect(host, user, pass, dbname)` — Установка PDO-подключения к PostgreSQL
- `register(name, pass, imagepath)` — Регистрация нового пользователя (с валидацией полей)
- `login(name, pass)` — Авторизация пользователя (установка сессий)

---

## Связи между сущностями

- **Account — BookUser:** 1 к N.  
  *Один аккаунт может добавить в избранное и оценить множество книг.*

- **Book — BookUser:** 1 к N.  
  *Одна книга может быть добавлена в избранное множеством пользователей и получить множество оценок.*
